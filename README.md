# Desaf-o2
# Biblioteca Digital

Desafío Práctico #02 — Programación Orientada a Objetos (POO404)
Universidad Don Bosco

Sistema de escritorio en Java (JFrame) para administrar libros, autores 
y categorías de una biblioteca digital, conectado a MySQL mediante JDBC.

## Tecnologías
- Java (NetBeans)
- JDBC + MySQL
- JFrame, JTable, PreparedStatement
